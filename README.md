# ai-password-entropy

Are passwords generated by AI assistants actually secure? This project compares passwords produced by **Claude**, **Gemini** and **ChatGPT** against cryptographically random passwords, human-chosen passwords and the RockYou leak, using entropy metrics and statistical tests.

📝 **Blog post:** [Are AI-Generated Passwords Really Secure?](https://medium.com/@TheObz3v/are-ai-generated-passwords-really-secure-3ae48b7c293d)

## Datasets

| Group | Source | File |
|---|---|---|
| Random | Generated with Python's `secrets` module | `Randompasswords.txt` |
| Claude | Passwords generated by Claude Sonnet (exact version not recorded; generated in January 2026) | `AI_password_claude.txt` |
| Gemini | Passwords generated by Gemini | `AI_password_gemini.txt` |
| ChatGPT | Passwords generated by ChatGPT | `AI_password_chatgpt.txt` |
| Human | Passwords chosen by people | *not included (private)* |
| RockYou | The RockYou leak (first 1,000 entries) | *not included (download separately)* |

## Metrics

- **Shannon entropy**: character-frequency entropy of each password, in bits.
- **Effective entropy**: `log2(charset^length)` with penalties for repeated characters, single-case and digit-only passwords.
- **Search space reduction ratio**: effective entropy divided by the ideal entropy of a 94-character alphabet at the same length.
- **zxcvbn score** (0–4): Dropbox's pattern-aware strength estimate, if the `zxcvbn` package is installed. It is plotted but not included in the statistical tests.

Groups are compared pairwise with the **Mann–Whitney U** test (do the medians differ?) and the **Kolmogorov–Smirnov** test (do the distributions differ?).

## Files

The code in `code/` is the version submitted with the project, and it produced the results in the article.

| File | Purpose |
|---|---|
| `code/metrics.py` | Loads the datasets, computes the metrics, draws box plots and runs the statistical tests |
| `code/stats.py` | Mann–Whitney U and Kolmogorov–Smirnov comparisons |
| `code/plots.py` | Draws significance heatmaps from the p-values recorded in the file |
| `code/randomPassssword.py` | Generates the random baseline passwords |
| `checker_ANSSI.py` | An educational password checker based on ANSSI guidelines |

`sources/` holds two reference papers: *A Maturity Model for Password Security Education* and Herlands et al. (CSET '14).

## Running it

Run the scripts from the repository root, where the datasets are:

```bash
pip install "matplotlib<3.11" scipy zxcvbn   # code/metrics.py uses boxplot(labels=...), removed in 3.11
python code/metrics.py   # computes everything, shows the plots and prints the tests
python code/plots.py     # draws the significance heatmaps
```

**Sample size:** as in the article, only the first 100 passwords of each Random and AI file are analysed, plus the 41 human passwords and the first 1,000 RockYou entries. The files contain more (Random 1,100, Claude 1,100, ChatGPT 1,058, Gemini 5,000).

`code/metrics.py` also expects two files that aren't in this repo:

- `rockyou.txt`: the public RockYou wordlist, placed in the repository root.
- `PasswordsHuman.txt`: one password per line. The original human set is kept private. Use your own sample, or remove the Human group from `code/metrics.py`.

To regenerate the random baseline:

```bash
python code/randomPassssword.py > Randompasswords.txt
```

## Notes since publication

The article is left unchanged. It analysed the first 100 passwords of each Random and AI file; running the same code on every password changes some of the pairwise results. To reproduce, change `limit=100` to `limit=None` for those files in `code/metrics.py`.
